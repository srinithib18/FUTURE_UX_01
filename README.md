Vistara Interior Design Website Redesign

## Project Overview

Vistara is an interior design company specializing in luxury residential and commercial spaces. This project focuses on redesigning the website to improve user experience, strengthen brand credibility, and increase consultation requests through a conversion-focused interface.

## Problem Statement

Many interior design websites struggle with:
- Unclear service presentation
- Weak call-to-action placement
- Poor visual hierarchy
- Low lead conversion rates

The goal was to create a modern website that clearly communicates services and encourages potential clients to contact the business.
